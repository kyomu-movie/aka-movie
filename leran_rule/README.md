# 共有学習データ

- `approved/`: オーナーが明示的に承認し、次回から全員へ反映する再利用ルール。
- `candidates/`: オーナーだけが扱う未承認候補。メンバーは作成・編集せず、公開もしない。
- `successes/`: オーナーが承認した成功例の短い要約とメタデータ。画像・動画本体は入れない。

## 承認の流れ

1. メンバーの完成動画への `OK` で、動画、確認メモ、匿名化されたアニメーション要約をドラフト PR にする。
2. オーナーが動画を承認した後、Codex が学習案をチャットに表示する。この時点では学習ファイルを変更しない。
3. オーナーが学習案を明示的に承認した場合だけ、`approved/` と `successes/` を更新する。
4. 公開する変更ファイルを再確認し、オーナーの明示的な承認後だけ GitHub へ push する。

変更は GitHub へ反映する前に必ず確認し、個人情報・機密台本・出力画像は保存しない。これはモデル自体の追加学習ではなく、承認済みの文章ルールと成功記録を次回生成時に参照する仕組みである。
