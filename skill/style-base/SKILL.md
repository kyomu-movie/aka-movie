# ステップ型図解の基本ルール

- 情報を詰め込みすぎず、ひと目で順番が追える3〜6要素に整理する。
- 見出しは赤、本文とアイコンは黒、背景は白を基本とする。
- 接続線と矢印は、何が先で何が後かを明確にする場合だけ使う。
- 文字は日本語で短く、図解の余白を優先する。
- アニメーションは既存パターンを選ばず、台本の意味のまとまりごとに動きを設計する。
- 位置、拡大、回転、透明度、描画、緩急を安全範囲で組み合わせ、基本は落ち着いた動きにする。
- 承認済みルールは品質基準と参考例として使い、新しい構図や演出を禁止する型にはしない。
