# aka-movie これだけやればOK 最短手順

この手順だけで、動画を作って GitHub の PR に出せます。コードは Codex に実行してもらえます。分からなくなったら作業を止め、エラー画面をオーナーへ送ってください。

> [!IMPORTANT]
> `main` と `leran_rule/` は触りません。共有するのは「完了動画共有フォルダ」`shared-videos/` だけです。GitHub のログイン画面や実行許可が出たら、自分で承認します。

## 1. 招待を受け入れたら、Codex に初回セットアップを頼む

動画を保存したい空のフォルダを Codex で開き、次をそのまま送ります。

```text
GitHub の kyomu-movie/aka-movie への招待を受け入れました。
このフォルダに初回セットアップをしてください。

- Git LFS を初期化する
- リポジトリを clone する
- npm install を実行する
- movie-create スキルをインストールする

GitHub のログイン、実行許可、私の操作が必要な場面では止まって教えてください。
```

Codex が完了を知らせたら、Codex を完全に再起動して、clone された `aka-movie` フォルダを開きます。

## 2. Codex に動画作成を頼む

次を貼り付け、台本と構図の希望を書きます。構図の希望がない場合は、その行を削除します。

```text
$movie-create を使って動画を作成してください。

台本:
（ここに台本を貼り付けます）

構図・デザインの希望:
（例: 左から右へ流れる構図。赤い矢印を使う。）
```

> [!NOTE]
> `$movie-create` は、project ID と同じ `video/<project-id>` の自分用ブランチを自動作成して切り替えます。自分でブランチ作成を頼む必要はありません。アニメーションも固定パターンから選ばず、台本に合わせて毎回組み合わせます。

## 3. 画面を確認して `OK` を返す

Codex は次の順で確認を求めます。

1. **画像**: 構図、文字、色、矢印を確認します。問題なければ `OK`、直すなら修正内容を伝えます。
2. **構造**: タイトル、関係線、ノード、注釈の内容と順番を確認します。
3. **アニメーション**: Codex が自動検査した後、「0〜1秒: タイトルを小さく拡大しながら表示」のような日本語の流れを示します。順番、強調、速さを確認します。

構造とアニメーションが問題なければ `OK` と返します。これで Codex が MP4 を描画します。

描画後に完成 MP4 が表示されたら、内容を確認して問題なければもう一度 `OK` と返します。

## 4. 完成動画に `OK` を返す

完成 MP4 を確認し、問題なければ `OK` と返すだけで完了です。Codex が次を自動で行います。

- `shared-videos/<project-id>/` への完成 MP4 と、台本・画像を含まないアニメーション要約の準備
- その動画フォルダだけの commit・個人ブランチへの push
- オーナー確認用のドラフト PR 作成

GitHub のログイン画面や実行許可が表示されたときだけ、自分で承認します。`leran_rule/` は共有・変更されません。オーナーが動画を承認した後、Codex が学習案をオーナーへ提示し、オーナーが明示的に承認した内容だけが次回へ反映されます。

## 絶対にしないこと

- `main` に直接 push しない
- `leran_rule/` を編集しない
- `export/` を Git に追加しない
- エラー時に force push しない

より詳しい説明は [メンバー向けセットアップ・利用手順書](member-guide-ja.md) を参照してください。
